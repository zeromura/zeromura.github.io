Privacy Policy

Last updated: November 9, 2026

1. Who this applies to

NOME_DO_APP ("the Tool") is a personal tool used by its owner with the owner's own TikTok account. It is not offered to the public, so it does not collect personal data from other people.

2. What data the Tool uses

  • TikTok account authorization: when the owner connects their TikTok account through TikTok Login Kit, the Tool receives an access token, a refresh token and the account's basic profile identifier (open ID).
  • Videos: the video clips the owner chooses to upload to their own TikTok account.

3. How the data is stored and used

The access tokens are stored only in a file on the owner's own computer. They are used only to send videos to the owner's TikTok account. The Tool runs on the owner's computer and has no server or database.

4. Sharing

The Tool does not sell, rent or share data with third parties. Data is exchanged only with TikTok, in order to upload the owner's videos.

5. Retention and deletion

Tokens stay on the owner's computer until the owner deletes them. Access can be revoked at any time in the TikTok account settings (Security and permissions), and deleting the token file removes all stored authorization data.
